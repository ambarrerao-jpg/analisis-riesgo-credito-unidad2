### Descripcion
Analisis enriquecido de 800 clientes para prediccion de riesgo de credito con Python y R.

### Contenido Notebook
1. Conexion Drive y carga dataset credito
2. Manipulacion datos (dplyr - Python/R)
3. Visualizacion corregida (5 graficos):
   - Dispersion: Historial_Credito vs Edad
   - Barras: Distribucion por Nivel_Riesgo
   - Histograma: Ingresos Mensuales
   - Boxplot: Deteccion atipicos monto credito
   - Mapa Calor: Correlacion variables numericas
4. Equivalencia en R con ggplot2
5. Normalizacion y estandarizacion con justificacion optimizacion
6. Deteccion atipicos con IQR y capping
7. PCA 2 componentes >85% variacion

### Conclusion 
La optimizacion del preprocesamiento (normalizacion + tratamiento atipicos + PCA) mejora la precision del modelo, reduce el sobreajuste y optimiza tiempos de entrenamiento.

### Herramientas
Python, R, Pandas, Seaborn, Matplotlib, ggplot2, Scikit-learn
